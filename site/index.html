Everything a server needs, one click away

Each feature runs the same commands an admin would type, with confirmations and automatic rollback for anything that could lock you out.

Overview & quick actions

Live CPU, memory, swap, network and disks. Change SSH port, root login, updates, fail2ban, hostname, time zone, swap and disk cleanup.

Terminal

Multiple shells per server, search, reliable paste, a shortcut-key bar and a compose box for long commands.

Files (SFTP)

Browse, edit, upload, download, permissions, archives and a root-mode for system files.

Kubernetes

Nodes, deployments, pods with logs and shell, services, ingress, secrets, Helm and an apply-YAML editor, via kubectl on the server. Installs k3s or microk8s in one click.

Traffic

See which IPs are hitting the server right now, which service or container they talk to, who is calling your web server (nginx, Apache, Caddy) and your databases, and block an address in one click.

Docker

Containers, images, volumes, networks, logs, stats and Compose projects.

Web server

Nginx / Apache sites, PHP, reverse proxies and free HTTPS certificates with Let's Encrypt.

Databases

MySQL / MariaDB, PostgreSQL, MongoDB, Redis, SQL Server and SQLite: install, users, backups, restore, key browser and a query editor.

Security audit

Scored checks for SSH, firewall, updates, accounts, permissions, kernel hardening, with one-click fixes.

Two-factor auth

Google Authenticator for SSH logins with QR enrolment, scratch codes and lock-out-safe enforcement.

Firewall, users, cron, processes

ufw / firewalld / iptables rules, blocked addresses, user and key management, cron jobs with timers, process control.

One-click service updates

See when nginx, Apache, PHP, Docker or a database has a newer package and update just that service, with a restart.

Backup & restore

Export every server, setting and snippet to one file; passwords and keys are encrypted with your passphrase.

Logs, snippets, tunnels, alerts

journalctl and log files, saved command snippets, SSH tunnels and resource alerts.

26 colour themes

Soft dark, deep dark and light palettes including Tokyo Night, Nord, Dracula, Catppuccin and GitHub Light.

Runs on every distro

Ubuntu, Debian, RHEL, Rocky, Alma, Fedora, openSUSE, Alpine and Arch, using apt, dnf, zypper, apk or pacman.

Install in a minute

No account, no agent on the server. You only need SSH access.

Download

Get the installer (recommended, with automatic updates) or the portable .exe that runs from any folder.

Add a server

Host, user and a password or SSH key. Optional sudo password, jump host and 2FA secret.

Connect

Open the Overview and manage the server. Risky changes are tested and rolled back automatically.

macOS: the app is not notarized yet. If macOS says it cannot be opened, right-click the app → Open, or go to System Settings → Privacy & Security and click Open Anyway. Updates on Mac are a manual download from the same page.
Windows SmartScreen: the app is not yet code-signed, so Windows may show "Windows protected your PC" on first run. Click More info → Run anyway. You can verify the SHA-256 of the file on the download page.
